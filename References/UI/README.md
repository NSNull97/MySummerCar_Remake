# UI Concept References

These images are concept references for `08A_UI_MENU_SETTINGS_AND_HUD.md`.

Use them for:

- overall atmosphere;
- panel hierarchy;
- amber focus accent;
- dark translucent surfaces;
- automotive/industrial tone;
- menu/HUD/settings composition.

Do not:

- use the images as runtime UI backgrounds containing baked text;
- treat generated text, labels, prices, version numbers, or logos as
  authoritative;
- copy text errors;
- assume every shown graphics option is actually supported;
- replace accessibility and navigation requirements with visual similarity.

Recreate the interface from project-owned layouts, styles, icons, strings, and
view models.

## Direction references

`Direction/` contains later user-supplied visual-direction images that refine a
bounded part of an approved screen. Each directory README records what is and is
not authoritative. These images remain review-only and are never runtime
dependencies.
