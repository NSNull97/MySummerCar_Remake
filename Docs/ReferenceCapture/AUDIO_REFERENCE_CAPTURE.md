# Checklist: audio reference

Donor audio — reference only. Raw recordings остаются вне Git; production sound должен быть newly authored. Не объявлять subjective notes точными acoustic measurements.

## Session setup

- [ ] Master/submix settings, output device, sample rate/bit depth and recorder version recorded.
- [ ] Auto gain, enhancement and noise suppression disabled where possible.
- [ ] Fixed listener position/state and synchronized video/input marker.

## P0 engine states

- [ ] Starter start/loop/end timing; successful and failed start.
- [ ] Idle, RPM/load bands, throttle transitions and engine stop.
- [ ] Gear/shift/clutch events.
- [ ] Interior/exterior, door/window openness and occlusion observations.

## P1 environment/interactions

- [ ] Asphalt/gravel/grass surface loops and slip/skid events.
- [ ] Tool, fastener, pickup/drop/impact and part install sounds.
- [ ] Door/gate/hood/trunk open, close, latch and blocked events.
- [ ] Rain intensity, indoor/outdoor ambience and zone transitions.

## Acceptance

- [ ] Event/state map, relative timing and context stored; no donor clip imported.
- [ ] At least 5 repetitions for short events; variants and silence/failure states logged.
- [ ] Relative level/filtering marked observational unless calibrated.
