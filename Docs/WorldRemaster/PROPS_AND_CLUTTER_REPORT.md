# Props and Clutter Report — 05A pilot

## Result

The production pilot includes reusable first-pass workbench, shelves, crate, drum, mailbox, firewood and yard/infrastructure groups. Placement is deliberately sparse so player, carried parts and vehicle routes remain readable.

These authored pilot groups validate the production pipeline; they are not direct raw-record replacements. Registry coverage for `StaticProp` is `0 / 531`, so every discovered source prop remains `Unassigned` with a grouped manual-art task.

No donor mesh or texture is used. Hero props, interaction-specific stable IDs, decals, clusters, authored UVs and controlled scatter profiles remain manual follow-up work.
