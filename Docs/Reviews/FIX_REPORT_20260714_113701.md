## 4. Исправленные findings

### `INTERACT-001` и `INTERACT-002`

`RaycastInteractionCandidateSource` теперь использует bounded non-alloc buffer и исключает только явно переданный held Rigidbody. Ближайший unrelated collider по-прежнему остаётся occluder. `PlayerInteractionController` обновляет exclusion перед каждым query.

`PhysicalCarryController` предоставляет текущий held body для query и использует один idempotent restore path для explicit release, target loss, disable и destroy. Restore безопасен, если target или Rigidbody уже уничтожен; collision-ignore pair и исходные Rigidbody properties восстанавливаются, когда объекты ещё существуют.

### `PLAYER-001` и `PLAYER-002`

`PlayerInputRouter.OnDisable` вызывает `FirstPersonMotor.ResetInputIntent`, обнуляя движение и crouch request. Новая pure utility `LookInputScaling` явно различает:

- pointer delta — degrees per pixel без frame scaling;
- gamepad/rate input — degrees per second × unscaled delta time.

Одна и та же конверсия используется обычным look и вращением held object.

### `ARCH-001`

Полный public constructor `GameServiceBindings` сохранён и по-прежнему требует все семь services. Добавлен узкий concrete overload `CreatePartial(IInteractionService)`, а не общий optional framework. Root предоставляет только diagnostic count/completeness и не раскрывает service locator. Consumers всё ещё должны получать dependency напрямую от concrete installer.
