## Donor behavior established

The donor has 26 fixed wiring connections, 52 endpoint FSMs and 26 primary wire
meshes. `battery_terminal_plus` and `battery_terminal_minus` are additional
derived cable-shoe presentations. `wiring_speaker_dash` is not an interactive
pair in this network.

Every ordinary endpoint uses the same interaction contract:

1. The globally registered wiring-mess object must be within `0.1 m`.
2. Pressing donor `Use` at either endpoint sends `CLOSELOOP` to its authored
   opposite endpoint.
3. `CLOSELOOP` is handled only in `Sound`, not globally. The first press arms
   an end and waits; the event sent to an unselected opposite end is ignored.
   Pressing Use at that opposite end sends the event back to the waiting first
   end. Only then does `Finish assembly` set `Installed=true` and show the wire.
4. There is no normal wiring-tool disconnection action. `RESETWIRING` and
   `NOTINSTALLED` are state/save/part-reset paths, not a second user click.
5. Multiple ends in a `0.1 m` cluster can be armed on the same press, but cannot
   complete without their opposite ends. Completion broadcasts `RESETWIRING`,
   clearing the other pending selections. Selecting a fixed harness does not
   require its opposite removable component to be installed yet.

The requirement is selection of both distinct ends, not an unconditional
minimum of two key presses. The optional MarkerRight ends are about 0.0973 m
apart, so one proximity cluster can reach both and deliver the handshake within
one press. That edge is covered separately; the separated MAIN harness pairs
cannot auto-complete on their first press. This is inferred from the two FSMs'
local event handling and geometry, not an executed optional-accessory capture.

The previous one-click interpretation in this report and its original test was
incorrect. Raw donor components `110128` and `105652` prove that the only global
transition is `RESETWIRING -> Init`; `CLOSELOOP -> Finish assembly` is local to
`Sound`. Builder `.63` and the revised runtime correct that error.

The engine block is not a prerequisite for body electrics. It gates the engine
branch together with each actual component: starter positive/ground, ignition
coil/plug wires and alternator. Battery, dashboard, steering column, lights,
fuel tank, radio/accessories and radiator endpoints use their own donor-evidenced
part availability.

The electrical wrapper has three separate fasteners, each with stages `0..8`:

- positive battery terminal;
- negative battery terminal;
- starter positive cable bolt.

The ground lead requires the first **mounting bolt of the starter** to be
loosened (`Stage < 8`), not the positive cable fastener tightened. Donor FSM
`113498` reads index 0 of starter GO `6293`; its comparison routes equal/less/
greater to `LOOP/ASSEMBLE/LOOP`. Marker `57844` / Screw `110254` is that first
7 mm mounting bolt. The authored binding is `mount.satsuma.engine-plate.starter`
and `fastener.satsuma.engine-plate-starter.boltpm-1`. This corrects the earlier
inverted and misbound gate. Battery-shoe presentation is derived: either the
starter-positive or battery-harness connection activates the positive shoe;
the ground connection activates the negative shoe.

`ElectricsOK` requires an installed battery, both installed/tight terminal shoes,
installed battery harness, installed ignition wiring and donor battery charge
above `97` (`9.7 V` in the project simulation). The fixed/non-removable wipers
additionally require `WiringSwitchLights`.

The donor wiper animation is a `0.5 s` outbound plus `0.5 s` return sweep over
`86 degrees`. Slow mode waits `3 s` between complete cycles; fast mode repeats.
Loss of power does not abandon a blade halfway through an already started
cycle. The dashboard knob cycles Off/Slow/Fast and is not itself removable.

The donor `Wiring/Shock` FSM also proves a hot-wiring hazard: with the battery
installed and charged above `9.0 V`, positive shoe bolted and battery harness
installed, `RESETWIRING` produces a spark. Its `SendRandomEvent` weights decode
to `DIE=0.005` and `OFF=0.995`. A dedicated engine-block `HOTINSTALL` path uses
the same outcome. Player death/electrocution authority does not yet exist in the
project, so this consequence is evidence-captured but intentionally not faked
inside the vehicle component.

## Project implementation

Builder `11A-V1d.63` creates all 26 exact donor wire presentations, all 52 exact
endpoint transforms, both terminal shoes and the exact three fastener mesh
pivots. `SatsumaElectricalSystem` owns project state and connection rules.
`SatsumaWiringConnectorInteractionTarget` is a modern explicit-collider adapter
for the donor's global distance checks. First use arms the nearby ends; use at
the paired ends installs the wires. Repeating use at the same end does nothing.
Transient pending ends are not written into save DTOs and are cleared on
restore/reset, completion or component disable; unavailable pending ends cannot
later complete a wire. Existing installed connections and schema 2 are retained.
Installed endpoints stop advertising interaction and connections cannot be
removed with the wiring tool. Targets use 0.1 m spheres instead of the former
0.028 m spheres, retain exact pivots, and participate in ray selection only with
the wiring-mess item. World occlusion is retained. This is a modern raycast
adaptation, not a claim to reproduce physical tool-position distance checks.

The endpoint audit found 52/52 unique ends with matching donor positions and
prompts. Radio and regulator prompts were corrected. Optional amplifier/CD,
gauges, markers, racing-radiator and subwoofer endpoints do not mean those
accessories are fully implemented: their runtime part presentation is absent
or only compatibility metadata exists. Do not report full accessory parity.

The save extension is schema 2 and stores stable connection names plus all three
fastener stages. Schema 1 from the earlier five-wire prototype is accepted and
migrated. Wiper mode/cycle state remains independently persisted. Windshield
rain clearing consumes the live fixed-wiper sweep without making the blades
detachable.
