# M05C — ручная проверка геометрии карты

## Открытие полного стенда

1. Открой проект в Unity `6000.3.11f1`.
2. Выполни `Tools > MSC Remake > World Transfer > Open Reference Overview`.
3. Дождись загрузки bootstrap, persistent, global и всех 49 сцен `World_cell_*`.
4. Не добавляй reference-сцены в Build Settings и не сохраняй ручные изменения в
   `LegacyImport/ReferenceOnly` — стенд всегда можно пересоздать.

Для Play Mode камера управляется так:

- `W/A/S/D` — движение;
- `Q/E` — вниз/вверх;
- `Left Shift` — ускорение;
- удерживать RMB и двигать мышь — обзор.

## Режимы просмотра

Меню `Tools > MSC Remake > World Transfer > 05C > View`:

- `Show Actual Meshes And Fallbacks` — полный диагностический слой;
- `Show Actual Meshes Only` — оценка формы и расположения мешей;
- `Show Bounds Fallbacks Only` — поиск отсутствующей геометрии/коллайдеров;
- `Show Structural Review Without Vegetation` — здания, дороги, terrain/water и
  инфраструктура без перекрывающей растительности.

## Что проверить

### Полная карта

- [x] Контур карты узнаваем и не содержит гигантских повторяющихся «шипов».
- [x] Главная дорожная сеть образует связные маршруты без очевидных телепортов.
- [x] Terrain, lake/water и shoreline находятся в одной системе координат.
- [x] Крупные агрегаты не висят далеко от карты и не повернуты на 90° ошибочно.
- [x] Между cell-сценами нет разрывов, вызванных отсутствием загруженной ячейки.

### Контрольные зоны

- [x] Home/garage около `(0, 0, 0)`: дом, гараж, подъезд и берег взаимно согласованы.
- [x] Town/church около `(-1221, 7, 121)`: церковь, дороги и соседняя застройка не пересекаются грубо.
- [x] Repair workshop около `(1725, 7, -302)`: здания и подъездная дорога расположены согласованно.
- [x] Island cottage около `(-676, -1, -536)`: остров, вода и строение совпадают по высоте/положению.
- [x] Highway bridge около `(2007, -3, -1834)`: мост, дорога и береговые поверхности состыкованы.

### Детальная оценка

- [x] Двери/окна/крыши находятся на соответствующих зданиях.
- [x] Заборы, столбы, провода и знаки не имеют очевидного неверного масштаба.
- [x] Pivot сложных объектов не приводит к неправильному rotation/scale.
- [x] Interior-геометрия не вынесена за пределы своих зданий.
- [x] В fallback-режиме отмечены именно отсутствующие меши/коллайдеры, а не молча пропавшие объекты.

## Как сообщить дефект

Выбери объект и скопируй из `WorldReferenceEntity`:

- `Stable Id`;
- `Donor Hierarchy Path`;
- `Semantic Category`;
- `Visualization Kind`;
- cell-сцену из Hierarchy.

К сообщению приложи скриншот, приблизительные координаты камеры и кратко укажи:
`неверная позиция`, `rotation`, `scale`, `pivot`, `пересечение`, `разрыв` или
`missing mesh`. Finding следует добавить в `M05C_GEOMETRY_DEFECTS.csv`; не
исправлять production-мир напрямую из reference-only стенда.
