# 10A — ручная проверка NPC foundation

Статус: visual/motion/streaming pass принят пользователем 2026-08-01; отдельный
ручной mid-route save/load результат не сообщался, автоматическая save-регрессия
`52/52` зелёная. Полный ростер 10B здесь не проверяется.

1. Открыть `Assets/Game/Bootstrap/Bootstrap.unity` и запустить Play Mode через
   существующий New Game flow.
2. Переместиться в `cell_-3_0` к трём 10A fixture-позициям: магазин, короткий
   маршрут Alpo и bus-linked anchor.
3. Проверить у каждой временной модели масштаб, вертикальное положение, кости,
   отсутствие разрыва mesh и проигрывание назначенного legacy clip без рывка.
   Teimo и Latanen остаются у своих anchor по роли, но их клипы не должны быть
   заморожены на первом кадре. Alpo должен непрерывно ходить туда-обратно по
   восьмиметровому маршруту: около 10 секунд в одну сторону при стандартном
   масштабе времени, разворачиваясь перед обратным проходом.
4. В Inspector компонента `NpcWorldRuntime` проверить три уникальных stable ID,
   activity/anchor/route, route progress и последние trace-записи.
5. Выйти за streaming radius `cell_-3_0`: materialized presentation count должен
   стать `0`, а логические instances и route progress должны сохраниться.
6. Вернуться: три presentation wrapper должны восстановиться из текущего
   состояния без duplicate ID и без сброса маршрута.
7. Сохраниться в середине roaming route, загрузить слот через существующий UI и
   проверить восстановление activity/route progress/flags/relationships до
   появления presentation.
8. Убедиться, что меню/HUD 08A, погода Enviro, предметы, needs/home и управление
   не изменились.

Ожидаемые ограничения: нейтральный временный материал, тестовый короткий маршрут,
отсутствие production bus binding, финального диалога/голоса и полного ростера.
Их нельзя трактовать как дефект 10A или как подтверждение 10B parity.
