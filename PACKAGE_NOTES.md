# Package Notes

Version: 1.0

This package changes only Milestone 08A and adds its approved image references.
It does not modify other milestone prompts.

Key changes compared with the previous 08A prompt:

- approved PNGs are authoritative, not loose concepts;
- exact reference file paths and hashes are required;
- layout decomposition is mandatory before implementation;
- Editor-only overlay/capture tooling is required;
- main menu and four settings pages have locked compositions;
- the default HUD is locked to the supplied minimal reference;
- numeric need percentages are explicitly approved for this HUD;
- unsupported features must remain truthful;
- final visual approval is reserved for the user.
