# My Summer Remake Save Master

Локальный Windows-редактор **native-сохранений нашего ремейка**. Нужен установленный .NET 9 Desktop Runtime x64; на рабочем компьютере проекта он уже есть. Unity и оригинальная My Summer Car для запуска не требуются. Сетевых запросов нет.

## Запуск

Запустите `My Summer Remake Save Master.exe` из папки готовой сборки `Builds/SaveMaster`. Не отделяйте EXE от соседних DLL и JSON-файлов. Из исходников можно запускать `Tools/SaveMaster/Start.cmd` после сборки.

1. Закройте игру перед заменой её сохранения.
2. Нажмите **Мои сейвы** или **Открыть…**. Можно перетащить файл в окно или передать путь первым аргументом EXE.
3. Выберите раздел слева. Поиск ищет по всему сейву: по русскому названию, исходному имени поля, ID объекта и значению.
4. Выберите поле, измените значение внизу и нажмите **Применить**. Правки пока находятся только в памяти. Дробные числа принимают точку или запятую.
5. **Настройка авто** открывает регулировки, жидкости, состояние деталей и показания симуляции. **Мастерская** позволяет изменять крепёж и выбирать отдельные подключения проводки. Ступень отдельного болта также можно изменить в таблице: состояние его группы согласуется автоматически. **Баланс…** меняет деньги вместе с журналом операций, **Дата…** согласованно изменяет календарь и тики. **JSON раздела** открывает вложенные данные для опытного пользователя.
6. Нажмите **Проверить**, затем **Сохранить…**. Просмотрите список «было / стало» и подтвердите запись. **Сохранить копию…** создаёт новый файл и никогда не перезаписывает существующий.

Горячие клавиши: `Ctrl+O` открыть, `Ctrl+S` сохранить, `Ctrl+Shift+S` копия, `Ctrl+Z` отменить, `Ctrl+Y` повторить, `Ctrl+F` поиск. При закрытии несохранённой рабочей копии есть предупреждение.

Версия приложения видна в заголовке окна. В **1.0.1** чтение, проверка контрольной суммы и подготовка поиска выполняются в фоне; редактирование включается после готовности всех данных. Ошибка чтения сохраняет предыдущую рабочую копию. Исправлена также привязка нижнего редактора к выбранной строке таблицы.

Если окно перестаёт отвечать, оставьте его открытым для диагностики. Этапы открытия записываются локально в `%LOCALAPPDATA%\MySummerRemakeSaveMaster\Logs`; журнал не содержит значений полей, но содержит путь к файлу и текст ошибки. Ничего не отправляется по сети. Проверки отзывчивости версии 1.0.1 прошли, однако описанное зависание после появления данных пока не воспроизведено и не считается подтверждённо исправленным.

## Поддержка

Начиная с **1.0.2**, поддерживаются native-документы **16, 17 и 18**, без миграции и изменения версии. Версия 18 включает схему сборки 3 с купленными деталями (`dynamicParts`). Все 15 текущих доменов доступны через дерево и таблицу: игрок, потребности, деньги, Satsuma, ключ, предметы, физические объекты мира, переносимый предмет, дом, электросеть, время, погода, NPC, услуги и трафик (некоторые пункты объединены в домены).

Если обычные значения нельзя изменить, проверьте сообщение под полем и строку состояния: там указана причина блокировки. Save Master 1.0.1 открывает документ 18 только для чтения; используйте актуальную **1.1.0**. Новые неизвестные версии по-прежнему доступны только для просмотра. В главном окне таблица служит для выбора поля; само значение вводится в нижней панели, затем нажимается **Применить**.

Открывается каждое скалярное поле присутствующего payload, включая вложенные состояния двигателя, колёс, деталей, болтов, регулировок, жидкостей, электрики и положения объектов. Неизвестные домены и версии доступны только для чтения и сохраняются без потерь. Структура, постоянные ID и версии защищены: редактор не создаёт отсутствующие машины, предметы или ещё не реализованные игровые системы. Коллекции проводки изменяются через специальный согласованный механизм.

Редактор **не поддерживает `defaultES2File.txt` оригинальной MSC**. Образец организации — дерево данных и ремонтные операции редакторов сохранений; исходники и ресурсы MSC Editor не использованы.

Стандартный путь: `%USERPROFILE%\AppData\LocalLow\DefaultCompany\MySummerCar_Remake\Saves\Native\slot-XX\current.save.json`. Папка может отличаться у сборки с другим company/product name — тогда используйте **Открыть…**.

## Настройка машины — версия 1.1.0

Нажмите **Настройка авто**, выберите машину и нужную вкладку. Светло-зелёные ячейки **Значение** редактируются прямо в таблице. Под ней — диапазон, смысл настройки и ограничения. Кнопка **Взять подсказку** подставляет рекомендованное значение только в выбранное поле. Это отдельные ориентиры текущего ремейка, а не команда «починить всю машину».

| Вкладка | Что доступно при наличии в сейве |
| --- | --- |
| Регулировки | Смесь карбюратора, распределитель, генератор, фильтр, 8 клапанов, метка распредвала и схождение |
| Жидкости | Топливо, масло, охлаждение, передний/задний тормозной контур, сцепление, загрязнение масла, крышки |
| Состояние | Износ и поломка 9 штатных механических деталей, состояние купленных расходников, аккумулятор |
| Симуляция | Сохранённые показания работы двигателя; вычисляемые значения доступны для просмотра |

Можно подготовить несколько правок на разных вкладках и нажать **Применить настройки**. Ошибка оставляет введённые значения в окне; корректный набор попадает в рабочую копию целиком и отменяется одним `Ctrl+Z`. Затем проверьте список изменений и используйте **Сохранить…** или **Сохранить копию…**.

Учтены текущие правила игры:

- Клапаны: впуск 4–10, выпуск 3–9; ориентиры 7 и 6. Это условные значения регулировки, не миллиметры. Значение смеси карбюратора тоже не равно фактическому AFR.
- Ориентиры обслуживания: масло 3 л, охлаждение 5,4 л; тормозные контуры по 1 л, сцепление 0,5 л. Старое сохранённое масло выше 3 л не блокируется: 3 л — ориентир, не предел DTO.
- Напряжение аккумулятора согласованно пересчитывает его нормализованный заряд. Состояние механической детали 0% включает поломку. Поднять процент недостаточно для снятия уже сохранённой поломки: отдельно снимите галочку **Сломано** при положительном состоянии.
- Давления, вентилятор и другие вычисляемые показания пересчитывает симуляция. Метка и схождение снятой детали доступны для просмотра: игра заново задаёт их при восстановлении свободной детали.
- Старые сохранения не получают выдуманные записи. Если клапанов или рабочего состояния ещё нет, сохранитесь в актуальной сборке ремейка и заново откройте файл.

Успешная проверка не гарантирует запуск двигателя: он также зависит от сборки, затяжки, проводки, топлива и состояния других узлов.

## Защита и восстановление

- При открытии проверяются формат, размер, уникальность JSON-свойств и доменов, даты и SHA-256. Повреждённый файл не открывается для редактирования.
- Оригинал не меняется при открытии, применении правок и отмене. Неизвестные поля внутри payload сохраняются; неизвестные поля оболочки приводят к отказу вместо молчаливой потери.
- Перед заменой создаётся отдельная резервная копия рядом с исходником с уникальным именем. Резервная копия содержит исходные байты и не перезаписывает игровой `.bak`.
- Новый файл записывается во временный файл, сбрасывается на диск, повторно проверяется и атомарно заменяет исходный. Небезопасного перехода к обычному копированию при ошибке атомарной замены нет.
- Если исходник изменился после открытия, запись блокируется. Его нужно открыть заново и повторить нужные правки либо сохранить свою работу в отдельный файл.
- Для восстановления откройте нужный бэкап и сохраните отдельную копию. При закрытой игре сохраните текущий `current.save.json` отдельно и замените его проверенной восстановленной копией. Внутренний `SlotId` не меняется: восстановление выполняйте в тот же слот.
- **Сохранить копию** переключает редактор на новый файл. Повторное сохранение затем относится к этой копии. Новая копия — экспорт/резерв, а не автоматически зарегистрированный игровой слот.

Ограничение совместной записи: сторонняя программа, переименовывающая файл ровно во время атомарной замены, может обойти предварительную проверку пути. Дополнительная проверка вытесненного файла обнаруживает такую гонку и сохраняет версии для восстановления, но не является общей транзакцией с игрой. Поэтому игра должна быть закрыта; запуск Unity Editor сам по себе не доказывает, что Play Mode выключен.

Локальный валидатор проверяет известные числовые ограничения и связи. Он не запускает игровую сцену и не заменяет полную проверку каталогов/контента и загрузку в игре. Неизвестный крепёж блокирует массовую правку вместо угадывания количества оборотов. Детали проверок и источник каталога — в `SCHEMA.md`.

Метаданные заголовка, в том числе `UpdatedUtc`, сохраняются; реальное время изменения видно по файловой системе. Это сохраняет точное представление чисел метаданных для совместимой контрольной суммы Unity.

## Сборка и проверки

```powershell
./Tools/SaveMaster/Build.ps1
dotnet run --project Tools/SaveMaster/Tests/SaveMaster.Tests.csproj -c Release
./Tools/SaveMaster/Tests/Verify-UnityCodec.ps1
```

Сборка не добавляет пакеты в Unity и не меняет runtime игры. Все проекты инструмента находятся вне `Assets`. .NET-зависимости — только стандартная библиотека и WinForms; сторонних NuGet-пакетов нет. Проба кодека использует отдельный временный Unity-проект в игнорируемых `Artifacts`, копирует только авторский код сохранений и не открывает игровой проект. Подробности проверок и ограничения результата приведены в `Docs/Save/SAVE_MASTER.md` репозитория.
