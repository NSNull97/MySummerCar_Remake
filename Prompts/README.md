Before each prompt:

- commit or stash current work;
- verify the previous milestone compiles;
- read the previous milestone report;
- update the prompt only when a concrete project constraint changed.

Do not paste all prompts into one request. That produces architectural pelmeni: everything technically exists, nothing is cooked.
