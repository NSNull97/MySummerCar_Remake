# ENVIRO 3 — РУЧНАЯ ПОДГОТОВКА ПЕРЕД MILESTONE 07A

Codex не может легально и надёжно скачать купленный Asset Store пакет вместо
пользователя. Импорт выполняется вручную в Unity Editor.

Сначала закрой:

1. `06A`;
2. `06B1`;
3. `06B2`;
4. `06B3`.

К этому моменту точная карта оригинала должна быть активным sanitized runtime
baseline, streaming должен быть проверен, а неправильный кастомный визуал двух
ячеек — отключён.

## Перед импортом

1. Убедись, что `MILESTONE_06B3_REPORT.md` даёт go для 07A.
2. Убедись, что baseline revision зафиксирован.
3. Закрой незакоммиченные опасные изменения или сделай отдельную ветку.
4. Сохрани копию проекта либо убедись, что Git clean.
5. Запиши текущие Unity и HDRP версии.
6. Сделай скриншоты/заметки текущего неба, Global Volume, света, fog и exposure.
7. Не удаляй текущую HDRP-заглушку до аудита 07A.

## Импорт

1. Открой проект в Unity.
2. Открой Package Manager.
3. Перейди в `My Assets`.
4. Найди `Enviro 3 - Sky and Weather`.
5. Скачай доступную версию.
6. Импортируй пакет в проект.
7. Не переименовывай и не перемещай vendor-папки.
8. Не правь исходники Enviro для устранения конфликтов.
9. Не добавляй Enviro demo scenes в Build Settings.
10. Не импортируй Azure Sky в production-сцены параллельно с Enviro.

## После импорта

Зафиксируй вручную или передай Codex:

- точное название и версию импортированного пакета;
- Unity Console errors/warnings;
- путь vendor-папки;
- появились ли Enviro asmdef-файлы;
- импортировались ли demo scenes и sample content;
- изменились ли HDRP Custom Post Process settings;
- изменились ли Graphics/Quality settings;
- создались ли новые scripting define symbols;
- работает ли поставляемая Enviro HDRP sample scene.

## Что не делать

- не копировать API-примеры из старых форумных сообщений вслепую;
- не добавлять прямые Enviro-вызовы в gameplay-классы;
- не включать одновременно Enviro clouds и HDRP clouds;
- не включать одновременно два fog-владельца;
- не использовать Enviro audio как окончательный audio backend;
- не покупать/подключать Enviro Terrain Shader только ради завершения 07;
- не править vendor shader/code, если интеграция с водой или HDRP выглядит
  неправильно — сначала зафиксировать проблему в 07A;
- не начинать массовый remaster donor baseline материалов ради мокроты.

## Если импорт сломал компиляцию

Не запускай 07B или 07C.

Запусти 07A: он должен провести аудит, локализовать конфликт и либо создать
минимальную безопасную интеграцию, либо остановиться с точным списком ручных
действий. Не разрешай Codex лечить ошибку массовым редактированием Enviro.
