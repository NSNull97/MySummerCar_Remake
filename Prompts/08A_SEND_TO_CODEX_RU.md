# Что отправить Codex перед 08A

Распакуй этот архив **в корень репозитория**, чтобы файлы оказались по путям:

```text
Prompts/08A_UI_MENU_SETTINGS_AND_HUD.md
References/UI/Approved/08A/...
```

Старый `Prompts/08A_UI_MENU_SETTINGS_AND_HUD.md` замени файлом из архива.

Добавь раздел из `AGENTS_08A_UI_REFERENCE_LOCK_ADDENDUM.md` в актуальный
`AGENTS.md`. Не заменяй весь локальный `AGENTS.md`, если в нём уже есть более
новые изменения других этапов.

После этого отправь Codex:

```text
Мы переходим к Milestone 08A.

Используй новый файл:
Prompts/08A_UI_MENU_SETTINGS_AND_HUD.md

Шесть изображений в:
References/UI/Approved/08A/
являются утверждёнными визуальными спецификациями, а не свободными концептами.

Нужно максимально точно воспроизвести их компоновку, пропорции, визуальную
иерархию и постоянный состав HUD. Не придумывай альтернативный дизайн.
Не используй изображения как готовые пиксели в runtime UI.

Перед реализацией:
1. Проверь наличие и SHA-256 всех шести файлов по manifest.
2. Создай decomposition документов, требуемых 08A.
3. Покажи план, найденный UI framework, существующие UI assets и конфликты.
4. Укажи, какие элементы на референсах пока не поддерживаются backend'ом и как
   они будут честно показаны как unavailable/placeholder.

После плана выполняй только Milestone 08A.
В конце создай reference/implementation/blended captures для всех шести экранов
и остановись для моего визуального ревью.
```
