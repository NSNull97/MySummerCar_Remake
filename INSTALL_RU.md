# Установка обновлённого набора промптов

Этот архив рассчитан на проект, где уже завершены и закоммичены milestones
`00`–`04`.

Ожидаемый путь к оригинальной игре:

```text
D:\SteamLibrary\steamapps\common\My Summer Car
```

Фактический корень Unity-проекта определяется по открытому репозиторию. Он может
называться:

```text
E:\GAYmDev_Studio\MySummerCar_Remake
```

или:

```text
E:\GAYmDev_Studio\MySummerCar_Remake_Game
```

## Как установить

1. Закрой Codex и Unity или хотя бы дождись, пока они закончат текущие операции.
2. Сделай резервную копию папки `Prompts` либо убедись, что всё закоммичено.
3. Распакуй **содержимое архива в корень Unity-проекта**.
4. Согласись заменить файлы в `Prompts`.
5. Не удаляй `Assets`, `Packages`, `ProjectSettings`, `Docs` и `Config`.
6. UI-концепты из архива попадут в `References/UI`.

После распаковки должно получиться:

```text
<PROJECT_ROOT>\
├── Prompts\
├── References\
│   └── UI\
├── Manifest\
└── NEXT_STEPS_AFTER_04_RU.md
```

## Что запускать первым

Поскольку `04_PLAYER_INTERACTION` уже завершён и закоммичен, не запускай
`00`–`04` заново.

Первый запрос в новом или текущем Codex-чате:

```text
Прочитай AGENTS.md и полностью прочитай Prompts/99_REVIEW.md.
Проведи только read-only ревью текущего состояния после завершённого
Milestone 04. Не исправляй код. Создай отчёт ревью и остановись.
```

После ревью переходи по инструкции в `NEXT_STEPS_AFTER_04_RU.md`.
